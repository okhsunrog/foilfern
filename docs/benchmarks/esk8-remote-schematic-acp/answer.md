**Unresolved / limitations**

- Nordic product-spec pages were blocked by a Cloudflare challenge; nRF52840 DEC/VDD capacitor values, VDDH/DCCH/DCC and unused-USB handling follow the Nordic reference design but are **not independently re-verified in this session**.
- VCC is generated by a separate AP2112K from VSYS rather than an AXP2101 rail, because AXP2101 default rail voltages/start-up order are OTP-customised; this guarantees MCU boot but should be confirmed against the ordered AXP2101 variant.
- **Main page remains visually crowded** (overlapping net labels around the dense 2.54 mm QFN symbol; right-side decoupling cluster). Power/UI are legible; Main needs a final spacing pass.
- USB data/DFU, ESD, battery NTC and reverse-polarity protection omitted; only SWD programming.
