FULL TOOL CATALOG
## autoroute

Route the unrouted connections of a board. backend: auto (default: Freerouting if installed, else builtin), builtin (grid router; supports nets/layers filters), freerouting. Place devices first.

## board_add

Add a board (default settings, 100x80 mm outline), or a copy of an existing board (copy_from: settings and all items).

## board_get

A board: outline, devices with pads, traces, vias, planes and the unrouted connections (air wires).

## board_legend_list

List the board and footprint texts on the configured silkscreen layers, with scoped targets, expanded text and transformed ink bounding boxes in board mm.

## board_polygon_add

Add a closed polygon to a board layer with vertices in mm, optional fill and stroke width. Use plane_add for copper connected to a net.

## board_requirements_check

Measure saved board requirements on the current boards. Reports hard blockers, warnings and pending anchored trace paths.

## board_requirements_get

Read the saved board requirements and revision. Rules use stable board, device, pad, net and copper UUIDs.

## board_requirements_set

Replace the project's saved board requirements as one undoable edit. Device regions, pad distances, trace paths, net routing rules and protected trace/via UUIDs are supported. Use expected_revision from board_requirements_get.

## board_set_outline

Replace the board outline: rectangle (width, height in mm, optional origin = bottom left corner and corner_radius) or polygon.

## board_text_move

Move an existing board or footprint text by its scoped target (or legacy UUID plus component), without moving its device or copper. Use board_legend_list to inspect silkscreen text.

## component_add

Add a component to the circuit and place all its symbols on a schematic page (free place if no position). `part`: device or component UUID or a name like "Resistor" / "LED 3mm" / "GND" (supply symbols). Library elements are copied into the project library. Selects the sole native purchasing part automatically; selected_part disambiguates alternatives. Returns pins and the actual purchasing selection. Free-space placement is a draft; follow foilfern://guides/schematic-design for a finished circuit.

## component_get

Details of a component: signals with nets (pin names for connect), placed symbols with pin positions, devices with pad positions.

## component_list

List all components: designator, value, library component, placement.

## component_remove

Remove a component with its symbols, wires at its pins and its devices on all boards.

## component_update

Change designator, value and/or attributes of a component.

## connect

Connect pins to a net (created or merged as needed) and draw the schematic: nearby pins are wired, distant pins get a stub wire with a net label placed clear of other items. Pins: "R1.1" (pad), "U1.VCC" (signal) or "GND1" (single-pin part). Unconnected supply symbols whose net name equals the net are attached (placed next to a pin). Call once per net with all its pins. Set assign_only for connectivity without drawing, then use design_preview for explicit paths.

## design_apply

Apply the exact patch from design_preview as one undo step. Stale previews and blocking design checks are refused. An empty patch adds no undo step.

## design_discard

Discard a completed design preview by its UUID without editing the project. Use design_preview_cancel for a running preview job.

## design_preview

Preview a version 1 design document for schematic edits, board placement or both. Board placement reports pose diffs, DRC, connectivity and saved requirements. Use board_layout.repair to propose local copper replacements and preview explicitly authorized branches with the placement. Schematic edits include nets, parts, fields, blocks and local wire paths, with ERC and annotation review. Compose new parts and their fields together; use wire_groups with pins and omit paths for automatic local wiring. Pin references use document keys. See foilfern://guides/schematic-design.

## design_preview_cancel

Request cooperative cancellation of the active design preview by its job UUID. Use design_preview_status to observe when it stops.

## design_preview_status

Read the active design preview job, current stage and latest terminal outcome. Poll while design_preview is running.

## design_rules_get

Read the board manufacturing profile in millimeters, including native design defaults, fabrication DRC constraints and current stackup selections.

## design_rules_preview

Preview a manufacturing profile patch without editing the board. Returns changed fields and the full-board DRC delta. Apply the same fields with design_rules_set and expected_revision from the preview.

## design_rules_set

Patch the board manufacturing profile in one undoable edit. Omitted fields keep their values. Use expected_revision from design_rules_preview, then project_save to write the board files.

## device_auto_place

Place all unplaced devices (or the given ones) inside the board outline by connectivity (connected devices close together, short air wires, connectors at the board edge, spread over the board), without overlapping footprints, keeping spacing (mm) and the board edge clearance. Deterministic.

## device_place

Place (or move) the device of a component on a board: position (mm), rotation (deg), side top/bottom, optional device/footprint UUID to change the footprint. New placements check and adjust blocked legend text; see initial_legend. Set include_pads=false to omit pad geometry.

## disconnect

Disconnect pins from their nets (removes the wires at the pins and traces at their pads).

## drc_run

## erc_run

Run the electrical rule check; returns ran=true and the messages (severity, text, location).

## export_bom

Export the bill of materials as CSV (also returned inline).

## export_fabrication

Export Gerber and Excellon fabrication files of a board (planes are rebuilt first).

## export_netlist

Export the IPC-D-356A netlist of a board.

## export_pick_place

Export pick&place data of a board as CSV.

## history

The undo history ("AI: <tool>" steps, done or undone) and whether there are unsaved changes.

## jobs_configure
