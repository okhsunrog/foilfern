# Esk8 Remote - schematic design notes

## Scope and engineering choices
- Bare nRF52840 SoC: **nRF52840-QIAA-R7** (aQFN73, LCSC C1851953) and **AXP2101** PMIC (QFN-40 + EP, LCSC C3036461).
  The request said AXP2102; AXP2101 was specified as the corrected part.
- Three pages: **Main** (MCU, clocks, antenna, decoupling), **Power** (charger/PMIC, USB-C, battery, 3.3 V housekeeping LDO), **UI** (display, buttons, trigger, SWD, LED).
- USB-C is charging-only (VBUS, CC1/CC2 5.1k, GND); D+/D-, SBU pins are no-connects. Programming is by SWD.
- The AXP2101 rail default voltages/start-up sequence are OTP-customised (datasheet: "Customization").
  To guarantee the MCU boots before I2C configuration, VCC = 3.3 V is generated by an **AP2112K-3.3**
  LDO from VSYS (always enabled). The AXP2101 provides charging, BATFET/VSYS, fuel gauge, PWRON key,
  IRQ and I2C control. Spare DCDC/LDO channels are intentionally unconnected and marked no-connect.
- Trigger interface: one 3-pin solder connector (VCC, SIG, GND) accepts either a 3-wire Hall sensor
  output or a potentiometer wiper. SIG has a 1k series resistor and 100nF to GND (SAADC AIN2).
- Display interface: 4-pin solder connector, pin order **1=VCC, 2=GND, 3=SCL, 4=SDA** (SSD1306 I2C).
- Button to PMIC: SW1 connects AXP2101 PWRON to GND (power on/off); no RC on PWRON.
  Other buttons are active-low to GND with 100nF hardware debounce, using internal pull-ups.

## GPIO / interface assignment
| Function | nRF52840 pin | Net |
|---|---|---|
| I2C SDA / SCL (TWIM0 defaults) | P0.26 / P0.27 | SDA / SCL (2.2k pull-ups to VCC) |
| AXP2101 interrupt | P0.28/AIN4 | IRQ (4.7k pull-up) |
| Trigger analog input | P0.04/AIN2 | TRIGGER (1k + 100nF) |
| Button UP / DOWN / SELECT / BACK | P0.11 / P0.12 / P0.13 / P0.14 | BTN_UP / BTN_DOWN / BTN_SEL / BTN_BACK |
| Status LED (active low) | P0.15 | LED_K, 1k + green LED to VCC |
| SWD | SWDIO / SWDCLK | J6 pins 2 / 3 |
| Reset | P0.18/nRESET | RESET, 10k pull-up, J6 pin 4 |
| 32 MHz crystal | XC1 / XC2 | 12pF load caps |
| 32.768 kHz crystal | P0.00/XL1, P0.01/XL2 | 12pF load caps |
| 2.4 GHz antenna | ANT | 0R series + DNP shunt, solder pad J1 |
| Unused GPIO, NFC, USB D+/D- | - | explicit no-connect |

## nRF52840 support circuitry
- VDDH tied to VDD (normal voltage mode, 3.3 V); DCCH tied to VCC; DCC, VBUS (USB unused), D+ and D- no-connect.
- 100nF on each VDD pin (VDD_1..5, VDDH) and 4.7uF bulk.
- 1uF on DEC1, DEC2, DEC3, DEC4, DEC5, DEC6 and DECUSB.
- 12pF crystal load capacitors; antenna matching footprint populated with 0R series and DNP shunt.

## AXP2101 support circuitry
- 1uF at BAT; two 22uF at VSYS; 10uF at VBUS (plus 10uF at USB connector).
- 1uF on VREF, VMID and CPULDOS.
- TS: 10k resistor to GND (fixed substitute for a 10k NTC; battery without thermistor per datasheet).
- SDA/SCK 2.2k pull-ups, IRQ 4.7k pull-up, PWRON key to GND, EP to GND.
- I2C address 0x68/0x69 (7-bit 0x34) as per datasheet; no address strap.

## Checks and known limitations
- `erc_run`: 0 errors, 0 warnings (native structural ERC; import metadata gaps reported).
- Netlist: 38 nets; all requested interfaces present; unused pins explicitly no-connect.
- Rendered all three pages and reviewed them. UI and Power are legible; **Main still has crowded net labels**
  around the dense 2.54 mm nRF52840 symbol (top and bottom rows, right-side decoupling cluster). This is a cosmetic
  remaining issue to fix by re-positioning labels/parts.
- AXP2101 default rail voltages are OTP-dependent; firmware must configure any rails it uses. Currently only charging,
  PWRON, IRQ and I2C are used, so no rail depends on OTP defaults.
- USB data, ESD protection, battery thermistor, reverse-polarity protection and fuel-gauge battery profile are not
  implemented; charging current/termination depends on AXP2101 defaults (300 mA / 4.2 V).
- No board, placement, routing or fabrication data was produced (later stage).
